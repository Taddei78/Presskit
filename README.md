# Taddei Presskit — Brazuka House

Presskit do DJ Taddei. Site estático (HTML + pasta `a/` com imagens, vídeos e áudio).

Publicado em: https://taddeibrazukahouse.netlify.app/

## Como publicar
- **GitHub Pages:** Settings → Pages → Branch `main` / pasta `/ (root)`.
- **Netlify:** conecte este repositório; não precisa de build (publish directory = raiz).
